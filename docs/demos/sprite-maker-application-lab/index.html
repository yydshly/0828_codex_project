THE REUSE PATTERN

复用的是动作资产，不是同一套业务。

五个场景共享角色身份、透明帧和动作版本；每个产品仍需构造自己的状态、数据、权限、反馈和成功条件。

ASSET LAYER一次制作，多处装载

master、run、cast 通过统一路径和版本进入不同产品。

STATE ADAPTER把业务状态映射到动作

例如“提醒完成”映射 cast，“移动到展品”映射 run。

BUSINESS LAYER每个场景独立拥有规则

课程进度不会被动画决定，营销事件也不会由 Rig 自动提交。

BOUNDARY无模型 · 无外部提交
