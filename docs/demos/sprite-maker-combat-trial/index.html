EXPLICIT COMBAT VERBS

复杂战斗不是动画猜测，而是显式时序合同。

视觉只跟随已经解决的模拟事件。每次命中都有稳定 action id；同一攻击不会重复伤害同一目标。

PLAYER / PULSE80ms startup · projectile active · 220ms cooldown

命中造成 1 点压力并积累 25% 同步；护盾先吸收伤害。

PLAYER / DODGE180ms travel · 220ms invulnerable · 850ms cooldown

用于穿过明确危险窗口；成功回避投射物额外获得同步。

COMPANION / SYNC CAST167ms startup · single contact · 250ms recovery

消耗 100% 同步；对护盾造成 4 点压力，对生命造成 2 点伤害。

ENEMY / ATTACKtelegraph → danger → contact → recovery

追击、远程、护盾和 Boss 改变决策压力，但都遵守可见预警。
