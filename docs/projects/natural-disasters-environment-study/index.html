01 / BOUNDARY

先确定它是什么，再讨论扩展。

仓库名叫 natural-disasters，但源码能力集中在开放海洋、天空、极端天气和电影化海上灾害。

IT IS

程序化海洋环境引擎

  • GPU 实时生成海面、云、雨、飞沫和闪电
  • 天气状态、灾害事件和摄影机共用一条时间轴
  • Director 自动演示与 Sandbox 自由操作双入口
  • 从 POTATO 到 ULTRA 的五档质量与自适应分辨率
IT IS NOT

通用自然灾害或科学模拟器

  • 没有地震、火山、山洪、森林火灾等陆地系统
  • 没有岸线、城市、真实海床和淹没计算
  • 灾害是电影化解析场，不是 CFD 或预测模型
  • 当前是可扩展源码，不是稳定的外部 SDK

05 / EXTENSION LADDER

可以扩展，但不是所有扩展都应该修改 Shader。

优先使用已有状态、幕次和事件组合；越靠后越接近新引擎，而不是“加一个配置”。

  1. LOW
    LEVEL 0

    环境预设

    晨雾、极夜、台风前夕、热带信风、红色夕阳。

    CONDITIONS + Weather.set()
  2. LOW–MID
    LEVEL 1

    新幕次与镜头

    重排天气、事件、时间和摄影机，形成新的可重复故事。

    Director acts + shots
  3. MID–HIGH
    LEVEL 2

    船只与海上资产

    加入 GLB、浮力、碰撞、海面采样、跟随镜头和任务状态。

    Three.js Scene + asset pipeline
  4. HIGH
    LEVEL 3

    新型海洋事件

    船尾波、连续风暴潮、冲击波组或新的解析涡旋。

    CPU / GLSL twin field
  5. REWRITE
    LEVEL 4

    岸线、城市与科学模拟

    真实海床、浅水方程、地形交互、建筑淹没与数据校准。

    new simulation architecture
