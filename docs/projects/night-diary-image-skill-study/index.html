01 / PROJECT 007 TESTS

先演示，再解释

两种构图，两次风格编辑，
一次真实的文字重试。

我们的独立实测基准图与编辑图均由本项目使用内置 imagegen 生成，不属于上游官方样片，也不代表跨模型成功率。

BEFORE AFTER
TEST 01 · VERTICAL城市窗景

构图锁 + 暖窗 + 精确文案

建筑、架空线、车、自行车和两个人物维持原位置；改变集中在夜色、现有窗光、颗粒和天空负空间中的三段文字。

  • 保持画幅、透视、主体数量与位置
  • 改变时间、局部光色、胶片质感与文字
  • 观察首轮把小写 some 自动大写，定向重试后修正
查看 Prompt 与一次重试记录

逐字文案：“some windows stay awake” / “(long after the street goes quiet)” / “to keep a little warmth alive.”

核心锁定：画幅、三组建筑、天空负空间、全部窗格、架空线、院落、门口、汽车、自行车和两个人物不可移动或增删。

重试：只要求把首字母 S 改为 s，并重新声明其余画面、文字、位置和质感全部保持。重试仍有轻微生成重绘，说明“只改一个字”不是像素级保证。

BEFORE AFTER
TEST 02 · LANDSCAPE海岸地平线

白昼转夜 + 几何与剪影保持

地平线、草坡、礁石、船和右侧人物仍在原有关系中；天空转为靛蓝，只保留原地平线已有的暖色余辉。

  • 保持水平线、船、人物、草坡与岩石关系
  • 改变夜色、云层质感、暗部与三段文案
  • 观察文案正确；局部海浪纹理被生成模型重新解释
查看 Prompt 摘要

逐字文案：“the sea keeps the last light” / “(a little longer)” / “before night takes it home.”

核心锁定：画幅、水平地平线、云带、草坡、礁石、左侧船和右侧唯一人物不可移动或增删；禁止月亮、星星、飞鸟和新光源。

质量门禁不是装饰

首轮偏差被留下，而不是被结果图掩盖。

源 Skill 要求检查文案准确性并最多定向重试一次。这个案例说明它能形成修复流程，也说明文字与局部像素仍由生成模型控制。

01B / USE-CASE DEMONSTRATIONS

不是多画几张，而是验证怎么被使用

同一张照片如何承载情绪，再进入真实内容容器。

DEMO 02 · EXPLICIT FIGURE BRANCH

WHAT THE DEMOS PROVE
  1. 情绪层

    用户选择方向并提供文案，Skill 负责把它翻译成光色、留白与文字语气。

  2. 分支层

    高风险人物处理默认关闭，只有明确要求才加入，并单独验收。

  3. 装配层

    图片是内容资产；封面、卡片和帖子仍应由确定性的产品界面承载。

    04 / CAPABILITY MAP
    
        
    
          
    能力不是一张滤镜
    它把风格、保护、文案和质检
    组合成一次完整编辑。
    
          
    
            
    01
    构图保护
    锁定比例、裁切、方向、主体数量、位置、姿态、透视与关键几何关系。
    
            
    02
    夜色重塑
    用深黑、靛蓝和暗褐建立负空间，让暖光只发生在已有光源附近。
    
            
    03
    图形质感
    加入胶片颗粒、轻柔光晕、旧纸磨损与少量不规则白色轮廓线。
    
            
    04
    叙事文字
    自动生成克制的三段式英文独白，或逐字使用用户提供的中文与英文文案。
    
            
    05
    场景适配
    为城市窗格、海岸天空、自然剪影和雨夜车窗改变局部策略。
    
            
    06
    显式分支
    只有用户明确提出时，才把现有人物转换为冷白荧光灯管轮廓。
    
          
    
          
    原图→语义构图锁 + 风格合同→宿主图片模型→人工 / Agent 质检
    
        
    
      
    

      
    
        
    05 / USE CASES
    从“能画什么”转为“谁为什么使用”
    主要价值是把已有照片，变成可复用的情绪内容资产。
    一句话边界它不读取或诊断人的情绪；用户提供照片、情绪方向与可选文案，Skill 负责以稳定视觉语言完成转译、保护和验收。
    
        
    
          
    01 · PERSONAL
    个人情绪与旅行日记
    适用对象
    个人创作者、摄影爱好者
    典型输入
    一张夜景或旅行照 + 当晚一句话
    交付产物
    情绪日记图、分享卡、回忆封面
    核心价值
    把私人感受转成可保存、可分享的视觉记录
    
          
    02 · CONTENT
    音乐、播客与诗性内容包装
    适用对象
    音乐人、编辑、播客与栏目主理人
    典型输入
    构图成立的主视觉 + 标题或短独白
    交付产物
    封面、歌单图、文章头图、诗集配图
    核心价值
    快速形成统一且有叙事感的内容气质
    
          
    03 · PRODUCT
    日记与心情记录产品
    适用对象
    日记 App、照片产品、轻量陪伴产品
    典型输入
    用户照片 + 主动选择的情绪 + 用户文案
    交付产物
    每日视觉卡、月度回顾、私人收藏页
    核心价值
    增强记录仪式感与内容留存，不承担心理诊断
    
          
    04 · SERIES
    品牌栏目与社交媒体系列
    适用对象
    品牌内容团队、城市文化与旅行栏目
    典型输入
    多来源摄影素材 + 固定风格合同
    交付产物
    系列帖子、栏目封面、活动预热视觉
    核心价值
    在不重做原图构图的前提下保持长期一致性
    
          
    05 · WORKFLOW
    团队视觉 Skill 工作流
    适用对象
    视觉 Skill、内容生产与生成式资产团队
    典型输入
    授权原图 + 构图不变量 + 文案 + 输出用途
    交付产物
    带 Prompt、版本、QA 与来源记录的可审计资产
    核心价值
    把个人审美升级为团队可复用、可回归的生产能力

    高匹配

      让模型预留文字区，再以 SVG/Canvas 或真实手写字库完成逐字排版和印刷输出。
      3. 
          
    3. P2
      模块与配置
      拆分构图核心、风格包、场景适配器、文案策略、人物后处理和质量门禁。
      4. 
          
    4. P3
      视觉回归
      固定授权测试图，记录模型版本、Prompt、输出、OCR、结构漂移和人工采用率。
      5. 
          
    5. P4
      生产与治理
      加入批处理、队列、成本、lineage、授权来源、保留期限和商业用途字段。

    07 / WHAT WE CAN LAND
    对我们的意义
    值得复用的是“构图保护型编辑合同”，
    不只是这一套夜景审美。
    
        
    
          
    共享底座
    Composition-Preserving Edit
    统一处理目标图选择、构图不变量、已有文字、重试次数、输出保存和验收记录。
    可服务全部图生图风格
    
          
    风格包
    Night Diary Recipe
    把色板、光源、颗粒、白线、文字语气和禁止项保留为独立、可版本化的审美配方。
    可替换而不动底座
    
          
    质量层
    OCR + Structure QA
    把“看起来差不多”升级为文字准确、主体数量、关键点、地平线和遮挡的可追溯检查。
    形成真正的工程壁垒
    
        
    
        
    
          
    固定插画配方主题 → 新图沐阳系列
    +
          
    构图保护编辑原图 → 风格化Night Diary 可参考层
    +
          
    概念化重构视觉本质 → 新资产Photo to Conceptual Art
    
        
    
        
    采用建议把它作为我们的图生图基准与架构参考；先抽取共享构图合同和质量门禁，再决定是否保留 Night Diary 作为一个具体风格包。不要把提示词本身误认为长期壁垒。
    
      
    

      
    
        
    08 / MATURITY & BOUNDARIES
    结论的证据边界
    结构清晰，样例有说服力；
    但仍是早期提示词型 Skill。
    
        
    
          
    已确认
    • Skill 结构校验通过
