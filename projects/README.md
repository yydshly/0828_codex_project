# 子项目研究区

这里保存每个研究对象的独立档案。一个目录对应一个研究主题，目录名使用稳定、可读的英文小写 slug。

## 推荐结构

```text
projects/<project-slug>/
├─ README.md       # 目标、过程、证据与结论
├─ assets/         # 可公开的截图、图表等材料
├─ experiments/    # 小型实验、测试或复现脚本
└─ source/         # 可选：外部仓库的 Git submodule
```

并非所有目录都必须存在；只添加研究实际需要并能够维护的内容。

## 开始一个研究项目

1. 复制 `_template/`，并按项目 slug 重命名。
2. 填写模板中的基本信息和第一个研究问题。
3. 在根目录 `README.md` 登记项目。
4. 在 `docs/projects.json` 添加对应展示卡片。
5. 提交一次仅包含项目骨架的变更，再开始累积实验记录。

如果外部项目有独立的版本历史，优先记录其远端地址和精确版本；需要在本仓库直接检出时，再考虑 Git submodule。
