# Project 008 · 必要总结

## 最终判断

`stickman-video-director` 不是视频生成模型，而是一套把“想法”编译为“可确认分镜和可执行镜头 Prompt”的导演协议。

它最值得复用的是导演中间层、批准门、镜头职责和连续性合同；火柴人只是默认视觉外壳，可以替换为我们的固定风格或品牌角色。

## 它解决什么问题

```text
原始主题或文案
→ 旁白重构
→ 六幕导演预案
→ 用户确认
→ 六条独立镜头生产合同
→ 外部视频模型生成
→ 外部剪辑、配音、音乐和拼接
```

适合在消耗视频生成额度前，把“想表达什么、每一幕承担什么职责、如何衔接”先变成可审核的生产计划。

## 它不解决什么问题

- 不提供视频模型或生成 API。
- 不自动生成、重试、下载或拼接视频。
- 不保证人物、声音、音乐或首尾帧跨镜头一致。
- 不提供成本管理、任务队列、批量生产或自动质量评分。
- 不等于无人审核的一键商业成片系统。

## 当前证据

| 证据 | 能证明 | 不能证明 |
| --- | --- | --- |
| 两条上游官方 MP4 | 明暗火柴人视觉方向可以实现 | 批量成功率、成本与跨主题稳定性 |
| 用户 20.01 秒实测 | motivation CLIP 01–02 可在一条文件中完成叙事和可识别衔接 | 内部是否拼接、模型版本、调用参数和重试次数 |
| 三类六幕研究案例 | 公开导演合同可以覆盖励志、科普和产品概念 | 真实视频模型一定遵循所有镜头合同 |
| 八种静态替代形象 | 火柴人可以被多种角色语言替换 | 视频动作、跨镜头身份一致性与生成成本 |
| 三套风格适配原型 | 导演不变量与风格覆盖项可以结构化分离 | 三种风格的真实视频效果 |

## 使用场景

直接适合：

- 知识解释、教育和视觉随笔。
- 励志、心理、习惯和行动类短内容。
- 抽象概念的线性隐喻。
- 生成前的客户或团队分镜确认。
- 统一视觉账号的批量选题与导演预案。

需要扩展：

- 品牌自有角色或固定 IP。
- 中文、多语言、字幕和 TTS。
- 多视频模型路由与失败回退。
- 三分钟以上长内容。
- 批量任务、成本、资产与质量管理。

不适合直接承担：

- 写实人物、多人表演、精确口型。
- 产品 UI 的像素级演示。
- 大量可读文字或精确数据图。
- 无人审核的一键商业成片。

## 对我们的意义

1. 它证明视觉经验可以从“临时写 Prompt”升级为可审核、可版本化的生产合同。
2. 它可以成为我们固定插画风格、品牌 IP 和多模型视频系统前面的导演控制层。
3. 它提供了一个低成本 benchmark：先比较导演协议是否提高可用片段率、连续性和采用率，再决定是否建设自动化执行层。
4. 它不增加底层模型能力，因此不能把导演方法的价值误写成模型质量提升。

## 当前采用结论

**采用导演协议，不直接照搬火柴人风格；暂不建设全自动视频流水线。**

### 现在

- 把它作为导演 workflow benchmark。
- 保留六幕、批准门、首尾状态和独立镜头合同。
- 用现有静态形象库筛选角色方向。

### 下一步

- 选择几何纸片人、黑色剪影、黏土小人和品牌吉祥物。
- 使用同一幕动作、同一视频模型和同一预算做受控 A/B。
- 记录可用率、重做次数、连续性失败、成本和耗时。

### 以后

只有真实回归证明导演协议明显改善采用率或降低重做成本，再建设：

- 结构化导演 Manifest。
- 多模型 Prompt 编译器。
- 角色与首尾帧连续性资产。
- 生成队列、预算、重试、QA 和后期合成。
