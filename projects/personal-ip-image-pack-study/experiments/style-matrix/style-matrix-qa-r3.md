# 林简 v1 · 真实风格矩阵 QA

## 结论

三组风格共用同一个 `character v1`，风格分别登记为 `s1 / s2 / s3`；切换风格不创建新人物。IP-02 与 IP-05 的六张新增图片均由 Codex 内置 ImageGen 实际生成，只使用本项目原创林简锚点作为人物参考，并依据上游文字风格规则描述视觉语言，没有把上游风格图片传入模型。

| 风格 | 身份 QA | 风格 QA | 任务 QA | 结论 |
| --- | --- | --- | --- | --- |
| `s1 / IP-04` 彩铅换装 | 圆脸、黑色中长发、圆眼镜、珊瑚上衣与藏蓝裤装保持 | 彩铅颗粒、全身人物与低饱和配色成立 | 头像和全身 READY；scene_card 按规范 BLOCKED | PASS |
| `s2 / IP-02` 清透扁平 | 三张图均保留人物锁；封面手势不改变身份 | 大色块、简化五官、轻描边和无复杂背景成立；仍存在少量柔和明暗，属于研究样例而非绝对无渐变基准 | 头像与封面 READY；全身按上游能力记为 CONDITIONAL 且完整显示双脚 | PASS WITH CONDITION |
| `s3 / IP-05` 手帐小剧场 | 三张图均保留人物锁和服装色板 | 手绘细线、纸张/铅笔质感、克制配色与留白成立 | 两张贴纸为真实 alpha；场景卡任务可读，但桌面同时含盆栽与书本，复杂度高于“单一场景元素”的严格目标 | PASS WITH NOTE |

## 文件事实

- 新增发布资产：6 张 PNG；总计 6 个新增文件均大于 1 MB。
- IP-05 半身贴纸：`1235 × 1274`，`Format32bppArgb`，四角 alpha 为 `0 / 0 / 1 / 0`。
- IP-05 全身贴纸：`1024 × 1536`，`Format32bppArgb`，四角 alpha 均为 `0`。
- 其余四张新增资产为明确实体背景，manifest 登记 `alpha: false`。
- 六张新增发布文件的 SHA-256 已写入 `style-matrix-manifest-r3.json`。

## 被阻塞和修复的中间产物

首轮两张 IP-05 贴纸都把棋盘格画进了 `Format24bppRgb`，四角 alpha 全为 255；半身贴纸还生成了未要求的装饰叶片。两项均被拒绝并保存在 `evidence/`。随后只进行背景提取与多余元素删除，最终文件通过真实透明通道检查。

## 研究边界

- 身份、风格和任务 QA 当前是人工规则验收，不是 embedding 或专用视觉模型评分。
- 这组结果证明三轴版本、风格路由与真实资产交付可以落地，不证明跨模型、长序列或真人肖像的一致性上限。
- IP-02 全身和 IP-05 场景复杂度应进入下一轮风格回归 Benchmark。
